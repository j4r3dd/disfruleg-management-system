# 🖥️ FAQ Técnico

## ¿Qué versión Python necesito?

Python 3.8+ (recomendado 3.10+)

## ¿Funciona en Mac?

✅ Sí, completamente compatible

## ¿Y en Linux?

✅ Sí, recomendado para servidor

## ¿Qué base de datos?

MySQL 8.0+ o PostgreSQL 12+

## ¿Puedo usar SQLite?

⚠️ No recomendado (múltiples usuarios)

## ¿Cuánto espacio ocupa?

~100 MB inicialmente, +100 MB/año
