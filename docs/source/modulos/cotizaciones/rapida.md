# 📦 Gestionar Compras - Referencia Rápida

## ⚡ 3 Pasos Rápidos

### 1️⃣ CREAR ORDEN
```
+ Nueva Orden
→ Proveedor: (selector)
→ Fecha Entrega: (fecha)
→ + Agregar Producto
→ Producto, Cantidad, Precio
→ Guardar
```

### 2️⃣ RECIBIR
```
Encontrar Orden
→ Botón "Recibir"
→ Verificar Cantidad
→ Notas (si hay diferencia)
→ Confirmar Recepción
→ Inventario actualiza
```

### 3️⃣ IMPORTAR
```
Importar Archivo
→ Selecciona Excel/CSV
→ Valida datos
→ Confirma importación
→ Ordenes creadas
→ Inventario actualizado
```

---

## 💰 Crear Orden

1. Botón: **+ Nueva Orden**
2. Completa:
   - Proveedor: (selector)
   - Fecha Esperada: (cuándo llega)
3. Clic: **+ Agregar Producto**
4. Para cada producto:
   - Producto: (selector)
   - Cantidad: 100
   - Precio Unit.: 10
5. Guardar

---

## 📥 Registrar Recepción

1. Encuentra orden en tabla
2. Botón: **Recibir**
3. Para cada producto:
   - Cantidad Recibida: (verifica)
   - Diferencia: (si hay)
4. Notas: (observaciones)
5. Confirmar Recepción

---

## 📁 Importar Archivo

1. Botón: **Importar Archivo**
2. Selecciona Excel/CSV
3. Valida datos mostrados
4. Clic: **Importar**
5. Órdenes creadas automáticamente

---

## 🔍 Buscar Compra

1. Campo: **Buscar**
2. Por número, proveedor o producto
3. Se filtra automático

---

## 📊 Fórmulas

```
Costo Línea = Cantidad × Precio Unit.
Total Orden = Suma de Líneas

Ejemplo:
100 kg × $10 = $1,000
50 kg × $20 = $1,000
Total = $2,000
```
