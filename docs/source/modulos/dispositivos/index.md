# 📱 Administración de Dispositivos

## Descripción

El módulo **Administración de Dispositivos** permite controlar qué dispositivos (computadoras, tablets, teléfonos) pueden acceder a BodegaDisfruleg. Es una herramienta de seguridad que gestiona sesiones activas, autoriza nuevos dispositivos y protege tu sistema contra accesos no autorizados.

### Funcionalidades Principales
- ✅ Ver todos los dispositivos autorizados
- ✅ Autorizar nuevos dispositivos
- ✅ Desautorizar dispositivos
- ✅ Ver información del dispositivo (IP, navegador, OS)
- ✅ Filtrar por estado (activo, inactivo, pendiente)
- ✅ Revocar sesiones activas
- ✅ Historial de accesos
- ✅ Control de seguridad

---

## 🎯 ¿Para Qué Sirve?

### Casos de Uso Comunes:

**🔐 Necesitas controlar quién accede**
- Computadora nueva en la oficina
- Empleado usa su propio dispositivo
- Prevenir accesos no autorizados

**📱 Necesitas autorizar nuevos equipos**
- Compra computadora nueva
- Empleado nuevos necesita acceso
- Dispositivo temporal

**❌ Necesitas bloquear dispositivos**
- Empleado se va
- Dispositivo fue robado
- Sospecha de acceso no autorizado

**📊 Necesitas auditar accesos**
- Quién accedió y cuándo
- De qué dispositivo
- Investigar actividad sospechosa

## 🔧 Conceptos Clave

### 📱 Dispositivo
Una computadora, tablet o teléfono que accede a BodegaDisfruleg.

**Información:**
- Nombre/descripción
- Dirección IP
- Navegador
- Sistema operativo
- Fecha de registro

### ✅ Autorizado
Dispositivo con permiso para acceder.

**Requisitos:**
- Registrado en el sistema
- Autorizado explícitamente
- Credenciales correctas

### ⏳ Pendiente
Dispositivo nuevo esperando aprobación.

**Proceso:**
1. Dispositivo intenta acceder
2. Sistema requiere aprobación
3. Administrador autoriza
4. Dispositivo obtiene acceso

### 🔴 Desautorizado
Dispositivo bloqueado del acceso.

**Razones:**
- Empleado se va
- Dispositivo robado
- Acceso no autorizado

## 📊 Flujo Típico

```
1. Empleado llega con computadora nueva
   ↓
2. Intenta acceder a BodegaDisfruleg
   ↓
3. Sistema reconoce dispositivo nuevo
   ↓
4. Solicita aprobación (pendiente)
   ↓
5. Administrador revisa dispositivo
   ↓
6. Autoriza el dispositivo
   ↓
7. Empleado puede acceder
   ↓
8. Acceso queda registrado
```

## 🎬 Ejemplo Práctico

### Escenario: Nuevo Empleado

**Día 1: Compra Computadora**
- Empleado llega con Dell/Windows
- Intenta acceder a BodegaDisfruleg
- Sistema: "Dispositivo no autorizado"
- Estado: PENDIENTE

**Día 1: Administrador Autoriza**
- Revisa información: Dell XPS, Windows 11
- IP válida de la oficina
- Haz clic "Autorizar"
- Estado: AUTORIZADO

**Día 2: Empleado Accede**
- Inicia sesión sin problemas
- Sistema registra: "Dell XPS autenticado desde IP 192.168.1.100"
- Acceso concedido

**6 meses después: Empleado Se Va**
- Antes que se vaya: revoca acceso
- Haz clic "Desautorizar"
- Dell XPS ya no puede acceder
- Protección de datos asegurada
