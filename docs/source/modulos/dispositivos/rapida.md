# 📱 Administración de Dispositivos - Referencia Rápida

## ⚡ 3 Acciones Principales

### 1️⃣ AUTORIZAR
```
Pestaña: Pendientes
→ Revisa información
→ Verifica que sea legítimo
→ Botón: "Autorizar"
→ Confirma
```

### 2️⃣ DESAUTORIZAR
```
Pestaña: Autorizados
→ Busca dispositivo
→ Botón: "Desautorizar"
→ Confirma
→ Dispositivo bloqueado
```

### 3️⃣ MONITOREAR
```
Pestaña: Todos o Activos
→ Ve lista de dispositivos
→ Estado de cada uno
→ Última actividad
```

---

## 📊 Pestañas

| Pestaña | Qué Ves | Acción |
|:---|:---|:---|
| Todos | Todos dispositivos | Monitorear |
| Autorizados | Con permiso | Desautorizar si necesario |
| Pendientes | Nuevos esperando | Autorizar |
| Desautorizados | Bloqueados | Re-autorizar si es necesario |
| Inactivos | Sin usar hace tiempo | Considerar desautorizar |

---

## 🔍 Información del Dispositivo

**Importante saber:**
- Nombre/Descripción
- IP (dirección)
- Navegador (Chrome, Firefox)
- Sistema Operativo (Windows, Mac)
- Fecha de registro
- Última actividad

---

## 🎯 Flujo Típico

```
1. Empleado nuevo intenta acceder
   ↓
2. Dispositivo aparece en "Pendientes"
   ↓
3. Administrador revisa información
   ↓
4. Verifica que sea legítimo
   ↓
5. Haz clic "Autorizar"
   ↓
6. Dispositivo en "Autorizados"
   ↓
7. Empleado puede acceder

---

Después de 6 meses, empleado se va:

1. Dispositivo sigue "Autorizado"
   ↓
2. Administrador la desautoriza
   ↓
3. Empleado ya NO puede acceder
   ↓
4. Datos protegidos
```

---

## ⚠️ Seguridad

```
✅ AUTORIZAR:
- Dispositivos legítimos
- IP de oficina
- Usuario conocido
- Navegadores estándar

❌ NO AUTORIZAR:
- Sin verificar
- IP sospechosa
- Usuario desconocido
- Configuración extraña
```
