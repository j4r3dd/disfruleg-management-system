# 📝 Generar Recibos - Referencia Rápida

## ⚡ FLUJO EN 30 SEGUNDOS

```
1. SELECCIONA GRUPO
   └─ [Grupo ▼] Selecciona

2. SELECCIONA CLIENTE
   └─ [Cliente ▼] Selecciona

3. BUSCA Y AGREGA PRODUCTOS
   └─ [Búsqueda] Escribe "pap"
   └─ [+ Agregar] Cantidad: 100

4. REVISA CARRITO
   └─ Subtotal ✓
   └─ Descuentos ✓
   └─ Total ✓

5. PROCESA PAGO
   └─ [PROCESAR PAGO]
   └─ Método (Efectivo/Cheque/Crédito)
   └─ [CONFIRMAR PAGO]

6. IMPRIME RECIBO
   └─ [IMPRIMIR]
   └─ Cliente recibe copia
```

## 💵 MÉTODOS DE PAGO

| Método | Proceso | Nota |
|:---|:---|:---|
| **Efectivo** | Ingresa monto recibido | Calcula cambio automático |
| **Cheque** | Número + Banco + Vencimiento | Verifica después en banco |
| **Crédito** | Valida límite disponible | Crea deuda automáticamente |
| **Transferencia** | Referencia de comprobante | Verifica después en banco |
