# 💰 Gestionar Precios

## Descripción

El módulo **Gestionar Precios** permite administrar los precios de tus productos de forma flexible y potente. Puedes establecer precios diferentes para cada grupo de clientes, aplicar ajustes, gestionar promociones y mantener un control centralizado de toda tu estructura de precios.

### Funcionalidades Principales
- ✅ Gestionar precios de productos
- ✅ Establecer precios diferenciados por grupo de cliente
- ✅ Aplicar descuentos y ajustes de precio
- ✅ Bloquear precios para evitar cambios accidentales
- ✅ Historial de cambios de precio
- ✅ Búsqueda y filtrado rápido
- ✅ Cálculo automático de márgenes
- ✅ Exportación de listados de precios

---

## 🎯 ¿Para Qué Sirve?

### Casos de Uso Comunes:

**💼 Necesitas diferentes precios para diferentes clientes**
- Mayoristas pagan menos que minoristas
- Empresas tienen precios especiales
- Clientes frecuentes tienen descuentos

**📊 Tienes muchos productos**
- Actualizar precios es lento
- Necesitas control centralizado
- Auditoría de cambios importante

**🔒 Necesitas evitar cambios accidentales**
- Bloquea precios críticos
- Solo administrador puede cambiar
- Historial de modificaciones

**💹 Quieres analizar márgenes**
- Costo vs precio de venta
- Margen de ganancia por producto
- Productos rentables vs no rentables

## 🔧 Conceptos Clave

### 📦 Precio Base
El precio de un producto para un grupo de cliente específico.

**Ejemplo:**
- Papa Blanca:
  - Precio Mayorista: $15/kg
  - Precio Minorista: $25/kg

### 📊 Grupo de Precios
Diferentes estructuras de precios para diferentes tipos de cliente.

**Ejemplo:**
- "Zona Centro" → Precios mayorista
- "Zona Periférica" → Precios minorista
- "Clientes VIP" → Precios especiales

### 🔒 Bloqueo de Precio
Protege un precio para evitar cambios accidentales.

**Uso:**
- Precios negociados especialmente
- Precios críticos que no deben cambiar
- Protección contra errores

### 📈 Margen
Diferencia entre costo y precio de venta.

**Cálculo:**
```
Margen = (Precio Venta - Costo) / Precio Venta * 100%
```

## 🎬 Ejemplo Práctico

### Escenario: Tienda de Frutas y Verduras

**1. Productos:**
- Papa Blanca (costo: $10/kg)
- Chile Serrano (costo: $20/kg)
- Limón (costo: $5/kg)

**2. Grupos de Precios:**
- "Mayoristas"
- "Minoristas"
- "VIP"

**3. Establecer Precios:**
- Papa Blanca:
  - Mayoristas: $15/kg (margen 33%)
  - Minoristas: $25/kg (margen 60%)
  - VIP: $20/kg (margen 50%)

**4. Al hacer una cotización:**
- Cliente mayorista: Paga $15/kg (margen bajo)
- Cliente minorista: Paga $25/kg (margen alto)
- Cliente VIP: Paga $20/kg (margen medio)

**5. Bloquear Precio VIP:**
- Es un precio negociado especialmente
- Nadie debe cambiarlo por error
- Bloqueado hasta que se apruebe cambio
