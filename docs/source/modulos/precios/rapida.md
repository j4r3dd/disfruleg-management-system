# 💰 Gestionar Precios - Referencia Rápida

## ⚡ 3 Pasos Rápidos

### 1️⃣ COSTO
```
Ingresa el costo del producto
Precio → Editar → Costo
```

### 2️⃣ PRECIO
```
Ingresa el precio de venta
Precio → Editar → Precio Venta
Margen se calcula automático
```

### 3️⃣ USAR
```
Al hacer cotización/recibo
Sistema usa los precios registrados
```

---

## 💲 Establecer Precio Base

1. Tabla de productos
2. Selecciona producto
3. Haz clic **Editar**
4. Completa:
   - Costo: $10
   - Precio: $25
5. Guardar

**Margen:** (25-10)/25 = 60% (automático)

---

## 📊 Precio por Grupo

1. Pestaña: **Precios por Grupo**
2. Botón: **+ Nuevo Precio**
3. Completa:
   - Producto: (selector)
   - Grupo: (ej: Mayoristas)
   - Precio: $15
   - Descuento: (opcional)
4. Guardar

---

## 🔒 Bloquear Precio

1. Selecciona precio
2. Botón: **Bloquear**
3. Ingresa motivo:
   - "Cliente VIP especial"
   - "Precio negociado"
4. Confirmar

**Efecto:** No se puede cambiar sin desbloquear

---

## 📈 Ajuste Masivo

1. Botón: **Ajuste Masivo**
2. Completa:
   - Tipo: Aumento
   - Porcentaje: 5%
   - Productos: Todos o seleccionados
3. **REVISA** cambios
4. Aplicar

---

## 🔍 Búsqueda

**Por nombre:**
- Campo "Buscar"
- Escribe nombre
- Se filtra automático

**Por margen:**
- Filtro "Rango Margen"
- Selecciona: 0-20%, 20-50%, etc.

**Por grupo:**
- Selector grupo
- Se muestran precios para ese grupo

---

## 📊 Margen

**Fórmula:**
```
Margen = (Precio - Costo) / Precio * 100%
```

**Interpretación:**
- ✅ >40%: Excelente
- ⚠️ 20-40%: Bueno
- ❌ <20%: Revisar

---

## 🎯 Flujo Típico

```
1. Ingresa Costo ($10)
   ↓
2. Ingresa Precio Base ($25)
   ↓
3. Crea Precio Mayorista ($15)
   ↓
4. Bloquea Precio VIP
   ↓
5. Usa en Cotizaciones
```
