# 🤖 UbicuoAI - Referencia Rápida

## ⚡ Flujo Rápido (3 Pasos)

### 1️⃣ PEGA (10 segundos)
```
UbicuoAI → Pegua el texto con productos
```

### 2️⃣ PROCESA (2 segundos)
```
Clic → "Procesar" o "Analizar"
```

### 3️⃣ REVISA Y ENVÍA (1-2 minutos)
```
Revisa productos ⚠️ amarillos
Corrige si es necesario
Clic → "Enviar"
```

---

## 📝 Formato de Entrada

**Simple (Recomendado):**
```
Chile serrano 6 kg
Papa Cambray 12 kg
Limón 3 kg
```

**También válido:**
```
6 kg Chile serrano
12 kg Papa Cambray
3 kg Limón
```

---

## 📊 Interpretar Resultados

| Color | Significado | Acción |
|:---|:---|:---|
| ✅ Verde | 95-100% confianza | Usar directo |
| ⚠️ Amarillo | 75-94% confianza | Revisar |
| ❌ Rojo | <75% confianza | Corregir |

---

## ✏️ Corregir Producto

1. Haz clic en la fila a corregir
2. Selecciona el producto correcto
3. Se guarda automáticamente

**Bonus:** El sistema aprende y la próxima vez se aplicará automáticamente.

---

## 🧠 Sistema de Aprendizaje

**Una corrección = Conocimiento permanente**

| Primera Vez | Segunda Vez |
|:---|:---|
| "aguacte" → 45% | "aguacte" → 95% ✅ |
| Corriges manualmente | Aplica automáticamente |

---

## 🎯 Unidades Reconocidas

| Tipo | Ejemplos |
|:---|:---|
| **Peso** | kg, g, gr, kilogramo, gramo |
| **Volumen** | L, ml, litro, mililitro |
| **Cantidad** | pza, pieza, caja, manojo, docena |

---

## 📤 Envío a Recibos

1. **Verifica:** Todos ≥75% confianza
2. **Clic:** "Enviar" o "Exportar"
3. **Listo:** Aparecen en módulo de Recibos

---

## 🚨 Problemas Rápidos

| Problema | Solución |
|:---|:---|
| Producto no encontrado | Corrígelo manualmente |
| Baja confianza | Revisa la ortografía |
| No se abre UbicuoAI | ¿Estás autenticado? |
| Muy lento | Procesa en lotes menores |

---

## 💡 Tips

✅ Pega directamente de emails/WhatsApp
✅ Un producto por línea es lo mejor
✅ La cantidad y unidad deben ser claros
✅ A más correcciones, mejor el sistema
