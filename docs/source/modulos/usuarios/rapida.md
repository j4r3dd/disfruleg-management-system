# 👥 Administrar Usuarios - Guía Rápida de Referencia

## ⚡ Acciones Más Comunes (30 segundos cada una)

### 🔑 Crear Usuario
```
Usuarios → + Crear → Completa datos → Elige rol → Guardar
```
**Campos obligatorios:** Nombre, Email, Usuario, Contraseña, Rol

---

### 🔐 Resetear Contraseña
```
Usuarios → Selecciona usuario → ⋮ → Resetear Contraseña
```
El usuario recibe email con link para cambiar en 24 horas.

---

### ✏️ Cambiar Rol
```
Usuarios → Selecciona usuario → Editar → Rol → Guardar
```
Automáticamente actualiza todos los permisos.

---

### 🚫 Desactivar Usuario
```
Usuarios → Selecciona usuario → ⋮ → Desactivar → Confirmar
```
Mantiene historial. Puede reactivarse después.

---

### 📋 Buscar Usuario
```
Usuarios → Campo "Buscar" → Escribe nombre/email/usuario
```
Se filtra automáticamente en tiempo real.

## 🆘 Problemas Rápidos

### ❌ "El usuario no puede acceder"
1. ¿Está **activo**? Si no, reactivalo
2. ¿Tiene **permiso Ver** en el módulo? Si no, agrega
3. ¿Olvidó contraseña? Resetea desde aquí

### ❌ "No recibe email de confirmación"
1. Verifica que el email sea correcto
2. Revisa carpeta de spam
3. Reenvía desde "Más opciones" → "Reenviar email"

### ❌ "Ve módulos que no debería"
1. Edita el usuario
2. Revisa sección "Permisos"
3. Quita lo que no necesita
4. Guarda (toma efecto en próximo login)

## ✅ Checklist antes de crear usuario

- [ ] ¿Email es único? (no existe otro usuario con ese email)
- [ ] ¿Usuario tiene email corporativo?
- [ ] ¿Qué rol necesita?
- [ ] ¿Está disponible para acceder hoy?

## 📞 Preguntas Rápidas

**P: ¿Puedo cambiar el usuario (login)?**  
R: No, debes eliminar y crear uno nuevo.

**P: ¿Cómo fuerzo cambio de contraseña?**  
R: Editar → Más opciones → "Forzar Cambio de Contraseña"

**P: ¿Diferencia entre desactivar/eliminar?**  
R: Desactivar = mantiene historial (recomendado). Eliminar = borra todo.

**P: ¿Cuántos usuarios puedo crear?**  
R: Sin límite (depende de plan).
