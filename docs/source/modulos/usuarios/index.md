# 👥 Administrar Usuarios

## Descripción

El módulo **Administrar Usuarios** permite gestionar todos los usuarios del sistema BodegaDisfruleg. Desde aquí puedes crear nuevos usuarios, asignar roles y permisos, editar información de acceso y controlar quién puede hacer qué en el sistema.

### Funcionalidades Principales
- ✅ Crear y registrar nuevos usuarios
- ✅ Asignar roles y permisos específicos
- ✅ Editar información de usuarios existentes
- ✅ Desactivar o eliminar usuarios
- ✅ Resetear contraseñas
- ✅ Ver historial de accesos
- ✅ Gestionar permisos por módulo
