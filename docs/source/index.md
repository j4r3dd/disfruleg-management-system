# 🚀 CHUMI - Cloud Hybrid Unified Management

## ¿Qué es CHUMI?

**CHUMI** (Cloud Hybrid Unified Management) es una **solución integral de gestión comercial** diseñada para pequeños y medianos negocios de venta de productos.

Es un **sistema todo en uno** que centraliza todas las operaciones de tu negocio en una única plataforma.

## 🎯 Flujo Típico

```
1. CLIENTE LLEGA → 2. CREAR RECIBO → 3. PROCESAR PAGO → 4. GENERAR COMPROBANTE
                           ↓
              SISTEMA ACTUALIZA AUTOMÁTICAMENTE:
              - Inventario -cantidad
              - Cliente +compra
              - Ganancias +venta
              - Si crédito → Deuda +X
```
