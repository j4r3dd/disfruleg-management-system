# 🚀 Primeros Pasos

## Para Dueño/Gerente

1. Lee [¿Qué es CHUMI?](../introduccion/overview.md) (5 min)
2. Lee [Requisitos](../introduccion/requisitos.md) (5 min)
3. [Instala CHUMI](instalacion.md) (30 min)
4. [Configura sistema](configuracion.md) (30 min)

## Para Vendedor

1. Tu admin instala CHUMI
2. Recibes usuario y contraseña
3. Lee [Guía de Recibos](../modulos/recibos/index.md) (20 min)
4. Practica con supervisor (30 min)
5. ¡Listo para vender!

## Para Administrador

1. Verifica [requisitos técnicos](../introduccion/requisitos.md)
2. [Instala CHUMI](instalacion.md)
3. [Configura sistema](configuracion.md)
4. Crea usuarios en [Usuarios](../modulos/usuarios/index.md)
5. Autoriza dispositivos en [Dispositivos](../modulos/dispositivos/index.md)

**Siguiente:** [Instalación](instalacion.md)
