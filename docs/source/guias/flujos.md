# 🔄 Flujos de Operación

## Flujo de Venta Diaria

```
INICIO DÍA
  ↓
REVISAR INVENTARIO
  ↓
LLEGA CLIENTE
  ↓
CREAR RECIBO
  - Cliente
  - Productos
  - Cantidades
  ↓
PROCESAR PAGO
  ↓
GENERAR COMPROBANTE
  ↓
SISTEMA ACTUALIZA AUTOMÁTICAMENTE
  - Inventario
  - Ventas
  - Deudas (si aplica)
  ↓
FIN DÍA - Reportes
```

## Flujo de Compras

```
NECESITO STOCK → CREAR ORDEN → ENVIAR → RECIBIR → REGISTRAR → INVENTARIO ACTUALIZA
```
