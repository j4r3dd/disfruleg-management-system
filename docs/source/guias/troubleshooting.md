# 🔧 Solución de Problemas

## Problemas Comunes

### "No puedo conectarme a la BD"

1. Verificar MySQL está corriendo
2. Verificar credenciales en .env
3. Verificar firewall
4. Reintentar

### "Sistema lento"

1. Verificar RAM disponible
2. Verificar conexión internet
3. Reiniciar aplicación
4. Contactar soporte

### "Olvidé contraseña"

1. Contactar administrador
2. Admin resetea
3. Usar temporal
4. Cambiar al iniciar

### "No aparecen productos"

1. Crear en Inventario
2. Definir precio en Precios
3. Actualizar módulo (F5)
4. Sincronizar si uses cloud
