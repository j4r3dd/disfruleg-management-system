# ⚙️ Configuración Inicial

## Paso 1: Crear Usuario Admin

1. Módulo → Usuarios
2. [+ Nuevo Usuario]
3. Completa datos
4. Rol: Administrador
5. Guardar

## Paso 2: Crear Grupos de Cliente

1. Módulo → Clientes
2. [Gestionar Grupos]
3. Crear: Mayorista, Minorista, VIP

## Paso 3: Crear Productos

1. Módulo → Inventario
2. [+ Nuevo Producto]
3. Nombre, código, costo
4. Stock inicial

## Paso 4: Definir Precios

1. Módulo → Precios
2. Para cada producto
3. Precio base y por grupo

## Paso 5: Crear Clientes Iniciales

1. Módulo → Clientes
2. [+ Nuevo Cliente]
3. Datos y grupo de precio
