# ✅ Requisitos del Sistema

## Hardware Mínimo

- Computadora Desktop/Laptop
- Procesador: Intel i3+ (2010+)
- RAM: 4 GB (8 GB recomendado)
- Disco: 500 MB libres
- Internet: 2 Mbps (si es híbrido)

## Software Requerido

- Python 3.8+
- MySQL 8.0+ o PostgreSQL 12+
- Git (para actualizaciones)

## Servidor

**Mínimo:**
- Procesador: i5, 8GB RAM, 100GB disco

**Recomendado:**
- Procesador: Xeon, 16GB RAM, 500GB SSD
